# 🎓 智育导航
## 基于大模型与高校知识增强的大学生成长智能决策系统


一个面向高校学生成长规划场景的 AI 智能决策系统。


---

# 📌 项目简介

随着高校学生规模不断扩大，大学生在专业认知、能力提升、职业规划等方面面临越来越多的问题。

传统生涯规划主要依赖人工指导，存在：

- 个性化指导不足
- 专业培养方案利用率低
- 学生无法准确了解自身能力差距
- 未来发展路径不清晰


**智育导航**基于大语言模型、高校知识库以及学生成长评价模型，构建面向大学生的智能成长决策系统。


系统通过分析：

- 学校培养目标
- 专业课程体系
- 学生个人信息
- 当前能力水平
- 未来发展目标


自动生成个性化成长规划方案，帮助学生明确大学四年发展路线。

# ✨ 核心功能


## 1. 学生画像构建

系统采集：

- 学校
- 专业
- 年级
- 目标方向
- 已有技能
- 当前困惑


构建学生成长画像。


---

## 2. 高校知识增强分析

系统结合：

- 学校培养定位
- 专业人才培养方案
- 专业核心课程
- 职业发展方向


让AI具备高校专业背景。


---

## 3. 成长能力评价

建立多维度能力模型：

包括：

- 专业基础能力
- 编程能力
- 实践能力
- 职业准备能力


输出：

- 综合成长指数
- 能力短板分析
- 提升方向建议


---

## 4. 大模型智能规划

调用大语言模型生成：

- 当前阶段分析
- 学习建议
- 技能提升路线
- 项目实践建议
- 就业/升学规划


---

## 5. 可视化成长展示

系统提供：

- 成长指数
- 能力雷达图
- 四年发展路线
- AI成长报告
